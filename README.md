# TrailQuest

A San Clemente Island hiking challenge dashboard prototype built as a simple static web app.

## Run it locally

Open `index.html` directly in a browser, or serve the folder with a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- hiking challenge cards
- progress stats
- leaderboard
- recent activity feed
- route map mockup
- simple interactive tracking behaviour

## Stack

- HTML
- CSS
- JavaScript
